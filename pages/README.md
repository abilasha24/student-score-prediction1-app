# Smart Fit - Online Fitness Learning and Management System

## Project Overview
Smart Fit is a web-based fitness learning and management system developed for Members, Trainers, and Admin.

## Features
- Member registration and login
- Member dashboard
- Trainer dashboard
- Admin dashboard
- Workout management
- Meal plans
- BMI tracking
- Payment integration

## Technologies Used
- HTML
- CSS
- JavaScript
- Bootstrap
- PHP
- MySQL

## Setup Instructions
1. Copy the project folder into XAMPP htdocs
2. Start Apache and MySQL in XAMPP
3. Open phpMyAdmin
4. Create a database named `smart_fit`
5. Import the file `smart_fit.sql`
6. Update database connection settings if needed
7. Open the project in browser:
   `http://localhost/smart_fit/`

## Project Structure
- `backend/` - PHP backend files
- `css/` - styles
- `dashboard/` - Member, Trainer, and Admin dashboards
- `index.html` - Home page
- `login.html` - Login page
- `register.html` - Registration page
- `pricing.html` - Pricing page
- `workouts.html` - Workouts page
- `contact.html` - Contact page
